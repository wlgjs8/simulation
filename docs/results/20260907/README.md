**광학 보정에 반응한 모델은 griponly 하나뿐이다.** 나머지 다섯은 ±5 안에서 평평하다(p ≥ 0.23).
griponly는 velocity proprio가 sentinel로 마스킹돼 **손목 이미지가 유일한 공간 입력**이므로 투영
오차를 홀로 전부 떠안는다는 예측과 일치한다. 동시에, 다섯 모델이 평평하다는 사실이 보드 배치
자체의 재현성을 보증한다(두 보드는 날짜·난수가 다르다).

순위: griponly는 **공동 꼴찌 → 2위**가 됐고, 1위와의 차이 29 vs 27은 유의하지 않다.

## 남은 경고

- **절대 수치는 배치에 민감하다.** 같은 광학·같은 시드를 동시 8로 돌리면 griponly 안착이 35까지
  올라간다(동시 12에서는 13). 서빙 정책의 샘플링 노이즈가 **서버 프로세스당 단일 키 스트림**이고
  동시 에피소드가 도착 순서로 소비하므로, 같은 시드가 원리적으로 재현되지 않는다. 보드끼리는
  배치를 고정해야만 비교 가능하다.
- 이번 240런 중 2건이 좌팔 `ChunkFollowerFault`(각도 0.1 rad 허용치)로 중단됐다(ph3_r4 s115,
  plain_r5 s132). 별도 fx336 런에서도 1건 있었다. 전부 좌팔이다.
- 오배치가 처음으로 0이 아니다(veldrop50 1, griponly 1). 색 판별은 여전히 표본이 적다.
- 주점(principal point)은 아직 정렬하지 않았다. 학습 카메라는 좌 (319.08, 229.52) / 우
  (316.93, 238.20)인데 sim은 중앙(320/240)으로 렌더한다. 좌팔 10.5 px ≈ 200 mm에서 5 mm.
