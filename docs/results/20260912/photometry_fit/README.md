# 셀 광도 피팅 기록 (2026-09-11 ~ 09-12, gpu12)

실기 손목 카메라 광도에 sim 조명·톤매퍼·재질을 맞춘 5라운드 탐색의 원본 기록이다. 스크립트는
실행된 그대로 보존했다(gpu12 절대 경로 포함). 유지되는 도구가 아니라 증거다.
결과는 [`config/photometry/cell_fit_20260912_t013.json`](../../../../config/photometry/cell_fit_20260912_t013.json)
프리셋으로 옮겼다. 이 프리셋은 **채점 기본값이 아니고**, 켜고 매긴 보드는 스톡 보드와 비교하지 않는다.

## 기준

- 실기: `robotics_lab/logs/flow_obs_am`(2026-09-10/11 배포 런)의 정책 입력 JPEG(q95).
  런마다 10프레임씩 뽑아 팔별 64-bin 휘도 히스토그램을 만들었다(`real_hist.py` → `real_hist.json`).
- 실기 카메라 모델: D405 AE가 90 fps 상한(9947 µs, gain 0)에 고착돼 있다. 즉 고정 선형 게인에
  255 하드 클립이다.

## 라운드

| 라운드 | 스크립트 | 결과 | 목적함수 / 바뀐 점 |
|---|---|---|---|
| 1 | `fit_light.py` | `results/fit_light.jsonl` (60) | 영역 6개 지표, op0 + 조명 7차원 |
| 2 | `fit_light2.py` | `results/fit2.jsonl` (90) | 알베도 하한 완화, 최고 7.30. 작업면 p95=255 고착 |
| 3 | `fit3.py` | `results/fit3.jsonl` (90) | **전체 프레임 CDF W1 + 포화 질량 페널티**, 테이블/볼트 재질 범위 확대, 최고 43.1 |
| 4 | `fit4.py` + `fit4_center.json` | `results/fit4.jsonl` (60) | 3라운드 최고점 주변 국소 탐색, 최고 22.2 |
| 5 | `fit5.py` + `fit5_center.json` | `results/fit5.jsonl` (60) | 4라운드 최고점 주변, **최고 t013 = 20.95** |

단일 실기 런과 실기 평균 사이의 W1이 좌 8.7, 우 9.3이다. 따라서 한 장면으로 도달할 수 있는
바닥은 약 18이다.

## 원인 진단 (서로 독립)

1. **톤매퍼**: Kit 기본 Iray-Reinhard(op 6)는 하이라이트를 말아 넣는다. op 1–8에서는 조명 세기와
   무관하게 팁 포화가 0.00%였다(`op_sweep.sh`). op 0(클램프)에서는 film/exposure 노브가 무효라서
   노출은 광량으로 정한다.
2. **그림자**: dome 비중이 작아 p10이 16(실기 56)이었다. dome 비중을 크게 올렸다.
3. **재질**: 테이블 선형 알베도 0.42 대 폼 텍스처 약 0.10 때문에 테이블 전체가 포화됐다. 회색 볼트는
   metallic 1.0이었다.
4. 팁 roughness는 무관했다(`rough_op0.sh`, op0에서 0.03–0.50 전부 팁 clip 10.5–11.1%).

## 한계 (다음에 쓸 사람이 알아야 할 것)

- sim 쪽 히스토그램은 진단용 **h264 mp4를 디코드**해서 쟀고, 실기는 JPEG q95다.
- 렌더는 **seed 100, 4초** 한 장면이다. 기준은 롤아웃 전 구간이다. 화면 구성 차이를 조명·재질이
  대신 흡수할 수 있다.
- 목적함수는 **전체 프레임 분포**라서 영역별 외형을 구속하지 않는다. t013의 회색 볼트 알베도 0.60은
  탐색 범위 상한에 붙어 있다.
