## 판정

1. **"운반 중 박스 앞에서 놓기"는 광도에 반응한다. 좌팔(회색)에서 그렇다.** 들어올린 회색 볼트를 박스
   밖에서 놓는 비율이 A 0.66 → C 0.38 → D 0.20으로 줄고, D는 짝 검정 p=0.001이다. 원인이 볼트의
   외형(D에서 흰색)인지, 조명 전체인지는 이 보드로 분리되지 않는다. B(톤매퍼만)는 효과가 없었고
   C(창문 sun·dome)부터 나타난다.
2. **같은 변경이 우팔(검정)을 망가뜨린다.** op0를 쓰는 세 조건 모두에서 우팔이 닫아도 잡지 못해
   안착이 20 → 5–9로 떨어진다. 그래서 좌팔 개선이 전체 안착 수로 이어지지 않는다.
3. **D가 실기와 같아졌다는 증거는 아니다.** 사다리에서 D는 회색 볼트·박스 외형이 실기와 달랐다. 이
   보드가 보여주는 것은 광도 입력이 정책의 운반 결정(놓을지 들고 갈지)과 우팔 파지를 크게 움직인다는
   점이다.
4. A는 40시드 29개로, 09-11 샘플 보드의 같은 체크포인트 35와 다르다. 배치 간 편차로 보고, 조건
   비교는 이 배치 안의 짝 비교로만 읽는다.
