## 판정

1. **G(t013 조명·재질 + Iray 톤매퍼)가 기존 리그보다 낫다.** 두 배치 모두 1위다(46, 53). 합산하면
   안착 72 → 99, p=0.005다.
2. **우팔 붕괴 = op0 톤매퍼는 재현됐다.** D → G 우팔 안착이 합산 12 → 35(24/3)다.
3. **D의 좌팔 손실 = t013 회색 볼트 재질은 재현됐다.** D → E 좌팔 안착이 합산 37 → 69(36/7)다.
   다만 이 재질이 좌팔을 해치는지는 렌더 조건에 달려 있다. op0(D)나 스톡 조명(F, 닫기→운반 0.35)에서는
   해치지만, Iray + t013 조명(G)에서는 좌팔 안착이 가장 많다(A → G 합산 43 → 70).
4. **운반 중 박스 밖 놓기에 대한 분리 보드의 해석은 고친다.** 분리 보드에서 E(스톡 크롬 볼트 + t013
   조명)는 0.16이었지만 재현에서 0.40으로 A(0.41)와 같아졌고, 합산하면 A와 차이가 없다(p=0.44).
   반면 **t013 회색 볼트 재질이 있는 조건은 모든 배치에서 낮다**: D 0.20 / 0.29 / 0.12, F 0.19,
   G 0.16 / 0.11. 스톡 크롬 볼트 조건은 A 0.66 / 0.46 / 0.41, B 0.59, C 0.38, E 0.16 / 0.40이다.
   운반 중 놓기는 조명보다 **회색 볼트 재질**(스톡 크롬 metallic 1.0 ↔ t013 무광 알베도 0.60)에
   반응한다.
5. 따라서 G는 두 효과를 함께 얻는다. 볼트 재질로 운반 중 놓기가 줄고, Iray 톤매퍼로 우팔이 유지된다.
   A는 배치마다 29–39로 흔들렸고 D는 23–24로 안정적이었다.
