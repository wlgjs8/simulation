# 볼트 나사산(렌더 전용)과 회색 볼트 머리 조사 (2026-09-14)

## 1. 나사산 — 구현

- `scripts/bolt_visual.py`: ISO 68-1 기본 미터나사 프로파일로 축 메쉬를 만든다. M12, 피치 1.75 mm,
  크레스트 P/8·루트 P/4 평탄부, 60° 플랭크, 오른나사 헬릭스, 끝단 45° 모따기이고, 법선을 포함한다.
  볼트당 정점 11,042개 / 면 11,088개다. `tests/test_bolt_visual.py`는 Isaac 없이 외곽 반경 ≤ 충돌 원통,
  ISO 골 깊이, 1회전당 1피치 진행, 끝단 모따기, 법선 방향을 고정한다.
- `EVAL_BOLT_VISUAL=threaded`(기본은 기존 원통):
  - 프로토타입 메쉬 하나를 class prim 아래에 두고, 각 볼트가 `{bolt}/thread`로 참조한다.
  - 축 충돌 원통은 `purpose=guide`로 렌더에서만 숨긴다.
  - 재질은 eval 리셋과 shared-stack 리셋 양쪽에서 `thread` prim에도 바인딩한다.
  - `summary.json`의 `photometry.bolt_visual`에 기록된다.
- 사다리는 변형별 `"bolt_visual": "plain" | "threaded"` 전환을 지원한다(`config/photometry/ladder_threads_*.json`).

### 물리 불변 검증
`EVAL_BOLT_VISUAL=threaded` seed 100의 초기 정착 후 볼트 20개 자세(`scene_materials.json`의
`initial_bolts`)가 기존 보드 `sb2_A_s100`과 **완전히 같다**(최대 |Δp| = 0.0, |Δq| = 0.0). 숨긴 원통이 그대로
충돌한다는 뜻이다. 재질 바인딩은 shaft/head/thread 60개다.

- 렌더 해상도별 나사산(에피소드 R100/R101): [`img/threads_resolution.jpg`](img/threads_resolution.jpg),
  [`img/threads_resolution_crops.jpg`](img/threads_resolution_crops.jpg). 여기서는 쥔 볼트의 축이 아래를

- 실기보다 약한 점: 실기 볼트는 광택이 있어 마루와 골의 명암 대비가 강하다. 무광인 G 회색 볼트에서는
  나사산이 부드러운 음영으로만 보인다.

### 렌더 해상도 (별도 발견)
Isaac 기본 앱 설정이 `rtx.post.dlss.execMode = 0`(Performance)이라서, 손목 카메라가 **320×240으로 렌더한 뒤
640×480으로 업스케일**한다(로그: "DLSS … Render resolution of (320, 240)"). 지금까지의 모든 보드가 이 조건이다.

| 모드 | 설정 | seed 100 첫 스냅샷 라플라시안 분산(좌/우) |
|---|---|---|
| DLSS Performance (기본) | — | 226 / 203 |
| DLSS Quality | `EVAL_RTX=/rtx/post/dlss/execMode=2` | 192 / 175 |
| DLAA (원본 640×480) | `EVAL_RTX=/rtx/post/aa/op=4` | 325 / 264 |
| 실기 (참고, 센서 노이즈 포함) | — | 475 (좌) |

DLAA가 가장 선명하지만 기본 모드에서도 나사산은 보인다. 기본값은 바꾸지 않았다. 바꾸면 광도 변경과
마찬가지로 보드 픽셀이 달라진다. 렌더 비용 차이는 재지 않았다.

## 2. 회색 볼트 머리 — 조사

실기 프레임 확대: [`img/real_bolt_heads.jpg`](img/real_bolt_heads.jpg)(`flow_obs_am/run_20260910_165659`, 우 32·좌 300).

| | 검정 볼트 | 회색 볼트 |
|---|---|---|
| 종류 | **소켓 캡 스크루** | **버튼 헤드 소켓 스크루** |
| 머리 | 원통형, 옆면 세로 널링, 윗면 육각 구멍 | 돔형(둥글고 낮음), 넓음, 육각 구멍 |
| 축 | 전체 나사산, 흑색 산화 피막(쥐면 금속 광택) | 전체 나사산, 은색 아연/스테인리스 광택 |
| 영상 판독 비율(참고) | 머리 높이 ≈ 축 지름(k/d ≈ 1.0) | 머리 높이 ≪ 축 지름, 머리 지름이 뚜렷이 넓음 |
| 규격표 기준값(M12 가정, **실측 아님**) | ISO 4762: dk 18, k 12, 육각 s 10 | ISO 7380-1: dk 21, k 6.6, 육각 s 8 |
| 현재 sim | 원통 dk 18.4, k 12 → **형상 일치** | 같은 원통 dk 18.4, k 12 → **형상 불일치** |

영상 판독의 한계: 640×480, 흐림, 원근 때문에 볼트마다 비율이 흔들린다(예: 검정 볼트 길이/지름이 1.5–2.1로
나옴). 종류 식별은 확실하지만 **호칭경·길이·머리 치수는 실물 캘리퍼스 측정이 필요하다.** 특히 회색 볼트의
길이는 검정과 같은 25 mm인지 영상만으로는 판단하지 못했다.

## 3. 다음 단계 제안 (미구현)

회색 버튼 헤드를 반영하려면 렌더만이 아니라 물리도 바꿔야 한다. 누운 볼트의 높이·기울기, 그리퍼가 머리에
멈추는 폭, 질량이 모두 달라진다.
1. 실물 치수 측정: 두 볼트의 d, L, dk, k, 피치.
2. 회색: 돔형 머리 렌더 메쉬(육각 구멍 s 8), 충돌은 돔 볼록 껍질 또는 원통 근사, 질량 갱신.
   검정: 육각 구멍(s 10)과 널링은 렌더만 추가한다(외곽이 같아 물리 무변경).
3. 회색 머리 충돌 형상이 바뀌면 `assets/scene_states40_aligned_rb5_foam.json`(정착 자세)을 새 형상으로 다시
   고정하고, 새 기준 보드를 다시 채점해야 한다.
