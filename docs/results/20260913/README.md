# 광도 사다리: 같은 손목 뷰로 본 기존 리그 ↔ 피팅 리그 ↔ 실기 (2026-09-13)

질문: 09-12 광도 피팅(t013)이 sim 손목 이미지를 실기와 **눈으로 보기에도** 더 비슷하게 만들었는가?
판단 목적은 std40 재채점이다. 재채점으로 보려는 것은 "파지 후 운반 중에 놓는 문제(색이 달라 보여서)가
줄었는가"다.

## 방법

`scripts/photometry_ladder.py`로 폐루프 에피소드를 스톡 리그 그대로 돌렸다. sim 시간 1초마다
물리를 멈추고(`delta_time=0`, step index 검사) 아래 네 단계를 차례로 적용해 양손 뷰를 무손실 PNG로
렌더한 뒤, 스톡으로 되돌렸다. 정책은 스톡 프레임만 보므로 **한 스냅샷의 네 열은 기하가 픽셀 단위로
같고 광도만 다르다.**

| 열 | 내용 |
|---|---|
| A 기존 리그 | Iray-Reinhard 톤매퍼, key 600 / dome 520, 작성된 재질 |
| B +톤매퍼 op0 | 하드 클램프만. 스톡 조명 비율을 유지하고, 첫 스냅샷에서 D와 중앙값을 맞춰 노출을 한 번 고정 |
| C +조명 | op0 + t013의 key/dome/sun, 스톡 재질. 노출 고정은 B와 같은 방식 |
| D +재질 = t013 | `config/photometry/cell_fit_20260912_t013.json` 전체 |

사다리 정의는 `config/photometry/ladder_20260913.json`이다. 에피소드는 gpu12에서 세 개를 돌렸다:
s100(8048 devjit@20k, 36 s에서 알려진 좌팔 `ChunkFollowerFault` ang 0.1002 rad로 종료),
s101(8044 devjit@40k, 60 s), s102(8042 cvac2x, 60 s). 팔별 158 스냅샷이고 원본은 로컬
`outputs/photometry_ladder_20260913/`에 있다. 렌더 수렴 잔차(마지막 두 프레임 평균 절대차)는
0.3–1.1로, 스톡의 렌더 노이즈 0.45와 같은 수준이다.

실기 열은 sim과 박스 배치가 같은 `flow_obs_am/run_20260910_165659`에서 같은 팔·같은 단계 프레임을
골랐다(`picks_left.json`, `picks_right.json`). 09-11 오전 런은 좌우 박스가 바뀌어 있어(좌팔 = 녹색
박스) 쓰지 않았다.

## 눈으로 본 결론

1. **D에서 회색 볼트가 음영 없는 흰 덩어리가 된다.** 포화 지도에서 D의 포화 질량은 거의 전부 회색
   볼트 몸통이다. 실기의 포화는 볼트 표면의 가는 반사줄, 햇빛 받은 팁 안쪽, 박스 테두리 점에 있다.
   피팅이 포화 **양**은 맞췄지만 **포화되는 물체**는 틀렸다. t013의 회색 볼트 알베도 0.60은 탐색 범위
   상한이다.
2. **박스 색이 틀어졌다.** 회색 박스는 D에서 짙은 남색이다(실기는 밝은 청회색). 녹색 박스는
   청록으로 과포화된다. 박스 주변 바닥면은 모든 열에서 실기보다 밝고, B·C에서는 통째로 포화된다.
3. **B·C(톤매퍼만, 조명까지)는 가장 나쁘다.** 스톡 재질이 하드 클램프에서 테이블·박스 영역을
   10–17%(좌) 포화시킨다. D의 재질 변경은 이것을 막았지만 1·2의 대가를 치렀다.
4. **팁은 어느 열에서도 포화되지 않는다.** 실기는 운반 중 팁 안쪽이 연노랑~흰색으로 포화된다
   (크롭 포화 4.7–7.1%).
5. 광도가 아닌 차이도 크다. sim 볼트는 나사산 없는 매끈한 원통이고, 실기에서 쥔 볼트는 팁 반사로
   금·은색 광택을 띤다. 실기 검정 볼트도 손에 쥐면 금속 광택으로 회색빛이 돈다(프레임 1장 관찰).

**판정: t013으로 std40을 재채점하지 않는다.** "운반 중 색이 달라 보여서 놓는가"를 보려는데, D는
바로 그 물체(쥔 회색 볼트)를 실기와 더 다르게 만든다. 재채점 전에 물체 단위 보정(회색/검정 볼트,
두 박스, 바닥면, 팁)이 먼저다.

## 부수 확인

- **mp4 측정 경로는 문제가 아니었다.** 같은 PNG를 `record_shared_stack`과 같은 imageio writer로
  인코딩하고 cv2로 디코드했다(`mp4_vs_png.py`, s101 33프레임). PNG↔mp4 W1은 1.04–1.09, 포화는
  mp4가 0.3–0.4%p 낮다. 팔당 W1 약 9 규모인 피팅 점수에 비해 무시할 만하다.
- 노출 고정(B·C)은 에피소드마다 첫 스냅샷에서 따로 맞춘다. 그래서 C의 스케일이 s100 0.74 /
  s101 0.67 / s102 0.96으로 다르다. 에피소드 간 C 열을 직접 비교하지 않는다.
