## sim 반영

- `config/bolts/measured_20260915.json`: `EVAL_BOLT_GEOMETRY`로 켠다. 반드시
  `assets/scene_states40_aligned_rb5_foam_measured.json`과 함께 쓴다(형상 sha가 다르면 실행을 거부한다).
- 임시 형상 대비 바뀐 점:
  - 회색: 길이 25 → **20**, 머리 21 × 6.6 → **20.5 × 6.0**, 윗면 반경 5.8 → 5.5
  - 검정: 충돌체 머리 지름 18.4 → **18.0**(검정 물리도 약간 바뀜), 널링 깊이 0.12 → 0.25 mm
- 질량: **저울 실측 검정 35 g, 회색 23 g**. 지금까지의 모든 보드는 검정 22 g을 가정했으므로, 검정 볼트는 약 60%
  무거워졌다(그리퍼 최대 힘 5 N 대비 파지 중 미끄러짐이 늘 수 있다). 강철(7.85 g/cm³) 환산 부피는 충돌체 부피의
  76%(검정)·80%(회색)로, 나사산 골과 육각 구멍의 빈 공간과 맞는다.
- `tests/test_bolt_visual.py`(13개)가 규격 범위(회색 d_k·r_f, 검정 d_k·k)와 널링 골·마루 지름을 고정한다.

## 새 초기 배치 (`frozen_scene_change.txt`)

같은 배치 규칙으로 실측 형상을 떨어뜨려 정착시켰다.
- 40/40 지지 검사 통과(바닥 오프셋 −0.26 ~ −0.02 mm).
- 무게 반영 후 다시 고정했다. 연장 정착이 필요했던 시드는 9개(최대 1750 스텝)다(무게 반영 전 3개, 임시 형상 14개).
- 회색 볼트 이동량(기존 배치 대비)은 중앙값 2.3 mm, 상위 10% 24.9 mm다(임시 형상 5.8 / 25.9).
  검정 볼트는 최대 2.3 mm다.
- 누운 자세 기울기: 회색 11.5°, 검정 6.8°.
